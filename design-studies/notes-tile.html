Three Fixes for Field Notes

Current tile: three-tier font jumps (30 → 20 → 16 px), 3 s minimum too brief for short quotes, long notes silently overflow 172 px. All three samples cycle the actual four notes at production scale.

304 × 172 px · production scale · live cycling
A Smooth Curve
Notes

A · smooth curve · 304 × 172
Font Sizing
Continuous formula replaces the three hard tiers. Size slides from 27 px for a 10-word note down to 14 px for the longest. No layout reflow or visual jump between consecutive notes.
size = clamp(14, 27 − len × 0.075, 27) px
Overflow
Gradient mask fades the bottom 38% of the body. Long notes look intentionally cropped — the tile feels like a window into the quote rather than a container that failed to fit it.
Timing
Word-count based. Short notes breathe; long notes don't overstay. The 5 s floor gives even a five-word fragment room to land.
ms = clamp(5000, words × 900, 9000)
Transition
Fade + 4 px vertical translate over 500 ms. Feels like turning a page — unhurried, directional, one motion.
B Fixed Stage
Notes

B · fixed stage · 304 × 172
Font Sizing
Eliminated entirely. Every note renders at 17 px / 1.38 leading. The eye settles into one reading rhythm and never re-calibrates between cycles. The tile feels typographically stable.
Overflow
Same gradient mask as A. Because the font is fixed, the fade point is always at the same visual height — the tile has a consistent "waterline." Long notes fade below it, short notes clear it.
Timing
Two-speed: short notes (≤ 50 chars) hold for 5 s; everything else holds for 8 s. Simple, predictable, easy to tune in one line.
ms = len ≤ 50 ? 5000 : 8000
Transition
Pure crossfade over 600 ms — no translate. Still-camera dissolve. Most appropriate for literary content where motion should not distract from language.
C Pull-Quote Slot
Notes

C · pull-quote slot · 304 × 172
Font Sizing
Fixed at 22 px — but only the first clause is extracted. Every note becomes structurally the same length on screen. Long quotes become apertures into a longer thought rather than problems to solve.
excerpt = text.split(/^.{12,60}?[.;!?]/)[0]
Overflow
By design, N/A. The excerpt constraint does the work upstream. The tile never needs to clip or fade because the content is always short.
Timing
Uniform 6 s for every note. Consistent cadence — the tile feels like a clock face. Works because all excerpts are approximately the same visual weight on screen.
Transition
Vertical slot: old note exits upward, new note enters from below. Mechanical, directional — a departures board or Solari flip. 400 ms cubic-bezier.
