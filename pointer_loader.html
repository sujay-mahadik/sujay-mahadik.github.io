01 — custom cursor

Circular pointer with inverse-theme hover

Three approaches to a custom cursor. All hide the native pointer and replace it with a circular element that reacts to hoverable content. Pick a style to try it live — move around the page.

A — difference blend ★ rec
White circle, mix-blend-mode:difference. Inverts any color beneath it — works in dark and light mode automatically. No JS color logic needed.
B — spark ring
Outlined circle that expands and fills with the amber/spark accent on hovered links and interactive elements. Matches the site's accent system precisely.
C — dot + trail ring
Small dot at the exact mouse position, plus a larger ring that lags slightly. More editorial/expressive — the ring turns spark on hover.

02 — loading screen

Full-screen preloader while content fetches

Three visual styles for the preloader. It covers the page until all Promise.all() fetches resolve in grid.js, then exits with an animation.

A — wordmark + progress bar
Italic "S." wordmark pulses while loading. A thin spark-colored bar fills to signal real progress. Minimal, typographic, on-brand.
B — curtain reveal ★ rec
Full dark panel slides up to reveal the page underneath. Fast, cinematic, zero extra elements. The exit animation becomes the first thing the visitor sees.
C — dot bounce
Three spark-colored dots bounce in sequence. Familiar, lightweight, works at any screen size. Simplest to implement.
03 — image loading

Skeleton shimmer + lazy intersection loading

Images in the bento grid currently load immediately with no feedback. Two improvements: a shimmer skeleton replaces the blank space while loading, and an Intersection Observer fires the actual fetch only when the card enters the viewport.

skeleton shimmer
Cards show an animated shimmer in the card background color until the image is fully downloaded. Works for both background-image and <img> elements.
blur-up reveal
Image appears blurred (from a cached tiny placeholder), then sharpens as the full image loads. Feels responsive even on slow connections.
lazy intersection ★ rec
Background images are stored in data-src and only loaded when the element scrolls into view — cuts initial page weight significantly.
